# turing-calculator
a calculator that does arithmetic by simulating a turing machine

planned features:
1. unary
2. binary
3. canary in the coal mine

# what's a turing computer?

you have three things:
1. a tape - inf strip of cells
2. a head - reads the current cell, writes, then moves either left or right
3. a state table - a set of rules that says "mm if i am in state x and i were to see a symbol y, then i'll write z, move left or right, and then switch to state w..."
